Step 1

Boot the NixOS minimal ISO

Download the NixOS minimal ISO — x86_64 Linux, minimal. Do not use the graphical installer; this guide assumes the minimal shell environment.

Flash it to a USB with Balena Etcher, or from a terminal. Verify the USB device with lsblk first:

sudo dd if=nixos-*.iso of=/dev/sdX bs=4M status=progress conv=fsync

Boot the target machine. Once at the shell, fix the font if the text is tiny:

setfont ter-118b
Step 2

Connect to the network

ping -c 3 nixos.org

If that succeeded — skip to Step 3. If you need Wi-Fi:

nmtui

Select Activate a connection, find your network, enter the password. Then ping again to confirm.

Do not continue until ping succeeds. Every remaining step requires internet access.
Step 3

Enable SSH and connect from your admin machine

On the target machine — type these three lines directly on its keyboard:

sudo passwd root sudo systemctl start sshd ip addr

On your admin machine, load your key and connect with agent forwarding:

ssh-add ~/.ssh/id_ed25519 ssh-add -l ssh -A root@<ip-address>
The -A flag forwards your SSH agent so git clone authenticates with GitHub through your admin machine. Your private key never leaves it.

All remaining steps run over this SSH session.

Step 4

Identify your disk and set variables

lsblk

Find your install target. Then set the three variables that drive every remaining command:

Also set the partition suffix — this detects whether your disk type needs a p between the name and partition number:

[[ "$DISK" == *nvme* || "$DISK" == *mmcblk* ]] && export P="p" || export P=""

Verify everything looks right:

echo "Disk: $DISK | Partitions: ${DISK}${P}1 / ${DISK}${P}2 | Host: $HOST | User: $NIXUSER"
If your SSH session drops, variables are gone — re-export all four before continuing.
Step 5

Partition the disk

Creates two partitions: 512 MiB EFI (FAT32, bootloader) and the remainder for root (BTRFS subvolumes). Layout is the same for both LUKS and plain installs.

wipefs -a $DISK parted $DISK -- mklabel gpt parted $DISK -- mkpart EFI fat32 1MiB 513MiB parted $DISK -- set 1 esp on parted $DISK -- mkpart primary 513MiB 100%
Step 6

Format the partitions

EFI always gets FAT32. The main partition is where the two paths diverge.

Select a host above to see your specific path.
without LUKS Both partitions formatted directly

The labels EFI and nixos matter — the config references disks by label, not device path.

mkfs.fat -F 32 -n EFI ${DISK}${P}1 mkfs.btrfs -f -L nixos ${DISK}${P}2
with LUKS Main partition wrapped in encrypted container

When cryptsetup luksFormat runs it asks YES in all caps. Enter and confirm your passphrase. There is no recovery — write it down first.

mkfs.fat -F 32 -n EFI ${DISK}${P}1 cryptsetup luksFormat --label nixos-luks ${DISK}${P}2 cryptsetup open ${DISK}${P}2 cryptroot mkfs.btrfs -f -L nixos /dev/mapper/cryptroot

Select a host at the top to see the right path for your machine.

Step 7

Create BTRFS subvolumes

Mount the raw filesystem temporarily, create all subvolumes, then unmount. Permanent mounts with the correct options happen in Step 8.

without LUKS
mount /dev/disk/by-label/nixos /mnt btrfs subvolume create /mnt/@ btrfs subvolume create /mnt/@home btrfs subvolume create /mnt/@nix btrfs subvolume create /mnt/@log btrfs subvolume create /mnt/@cache btrfs subvolume create /mnt/@snapshots btrfs subvolume create /mnt/@swap umount /mnt
with LUKS

Container is already open as /dev/mapper/cryptroot from Step 6.

mount /dev/mapper/cryptroot /mnt btrfs subvolume create /mnt/@ btrfs subvolume create /mnt/@home btrfs subvolume create /mnt/@nix btrfs subvolume create /mnt/@log btrfs subvolume create /mnt/@cache btrfs subvolume create /mnt/@snapshots btrfs subvolume create /mnt/@swap umount /mnt

Select a host at the top to see the right path for your machine.

Step 8

Mount everything

Each subvolume gets mounted at its permanent location with compress=zstd:1,noatime. The swap subvolume deliberately omits compression — BTRFS cannot host a swapfile on a compressed subvolume.

without LUKS
mount -o subvol=@,compress=zstd:1,noatime /dev/disk/by-label/nixos /mnt mkdir -p /mnt/{boot,home,nix,var/log,var/cache,.snapshots,swap} mount -o subvol=@home,compress=zstd:1,noatime /dev/disk/by-label/nixos /mnt/home mount -o subvol=@nix,compress=zstd:1,noatime /dev/disk/by-label/nixos /mnt/nix mount -o subvol=@log,compress=zstd:1,noatime /dev/disk/by-label/nixos /mnt/var/log mount -o subvol=@cache,compress=zstd:1,noatime /dev/disk/by-label/nixos /mnt/var/cache mount -o subvol=@snapshots,compress=zstd:1,noatime /dev/disk/by-label/nixos /mnt/.snapshots mount -o subvol=@swap,noatime /dev/disk/by-label/nixos /mnt/swap mount /dev/disk/by-label/EFI /mnt/boot
with LUKS

Source is /dev/mapper/cryptroot for all subvolumes. EFI is never encrypted — mount it directly from the labeled partition.

mount -o subvol=@,compress=zstd:1,noatime /dev/mapper/cryptroot /mnt mkdir -p /mnt/{boot,home,nix,var/log,var/cache,.snapshots,swap} mount -o subvol=@home,compress=zstd:1,noatime /dev/mapper/cryptroot /mnt/home mount -o subvol=@nix,compress=zstd:1,noatime /dev/mapper/cryptroot /mnt/nix mount -o subvol=@log,compress=zstd:1,noatime /dev/mapper/cryptroot /mnt/var/log mount -o subvol=@cache,compress=zstd:1,noatime /dev/mapper/cryptroot /mnt/var/cache mount -o subvol=@snapshots,compress=zstd:1,noatime /dev/mapper/cryptroot /mnt/.snapshots mount -o subvol=@swap,noatime /dev/mapper/cryptroot /mnt/swap mount /dev/disk/by-label/EFI /mnt/boot

Select a host at the top to see the right path for your machine.

Run lsblk to confirm all mount points are in place before continuing.

Step 9

Create the swapfile

Both paths rejoin here. The @swap subvolume was created without compression specifically for this — BTRFS enforces the requirement strictly and the kernel will refuse to activate a swapfile on a compressed subvolume.

btrfs filesystem mkswapfile --size 16G /mnt/swap/swapfile swapon /mnt/swap/swapfile
Size guide: 16G works for 16–32G RAM. For hibernation to work reliably, swapfile size ≥ installed RAM.
Step 10

Clone the config

Cloned directly to its permanent home under the user's home directory, then symlinked at /etc/nixos so NixOS tooling finds it. First verify variables are still set:

echo "Disk: $DISK | Host: $HOST | User: $NIXUSER"
Step 11

Generate hardware config

Detects filesystems, kernel modules, CPU and storage features. Written straight to the host's directory in the flake.

If installed with LUKS: confirm a boot.initrd.luks.devices section is in the generated file. If missing, check hosts/ThinkPad/default.nix for reference.
Step 12

Install

Reads the flake, resolves and downloads every package for this host, builds, and writes to /mnt. First install is slowest — cold cache. --no-root-passwd skips the interactive root password prompt.

If it exits with an error, scroll up past the activation output — the actual build failure appears well before the end.
Step 13

Set the user password

Do not skip this step. The user account exists but has a locked password. Skip this and you cannot log in after reboot.
Step 14

Reboot

swapoff -a umount -R /mnt reboot

Remove the USB when the machine powers off.

With LUKS: the system will pause before loading the OS and prompt for your passphrase.
